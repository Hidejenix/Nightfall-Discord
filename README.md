## 📖 О программе

**Nightfall Discord** — это приложение, которое позволяет отображать произвольные данные в вашем профиле Discord в виде статуса запущенной игры (Rich Presence). Гибкая настройка отображаемых данных и простой интерфейс делают программу удобной для повседневного использования.

## 🚀 Установка и запуск

### Шаг 1. Установите Python

Скачайте и установите **Python 3.15** с официального сайта:

👉 [https://www.python.org/downloads/](https://www.python.org/downloads/)

> ⚠️ При установке на Windows обязательно отметьте пункт **«Add Python to PATH»**.

### Шаг 2. Создайте приложение в Discord

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Нажмите **«New Application»** и задайте имя
3. Скопируйте **Application ID** (ID приложения)
4. Вставьте этот ID в программу при первом запуске

### Шаг 3. Скачайте программу

Загрузите последнюю версию:

👉 [**Скачать Nightfall Discord**](https://github.com/WPSQUAD/Nightfall-Discord/releases)

Распакуйте архив и запустите программу.

---

## 🖥️ Использование

1. Запустите приложение
2. Введите **ID приложения Discord**, созданного на шаге 2
3. Настройте отображаемые данные (название игры, подробности, состояние и т.д.)
4. Нажмите **«Запустить»** — статус появится в вашем профиле Discord

> 💡 Убедитесь, что Discord запущен на вашем компьютере — программа взаимодействует с ним локально через Rich Presence.

## ❓ Часто задаваемые вопросы

<details>
<summary><b>Статус не отображается в Discord</b></summary>

- Убедитесь, что Discord запущен
- Проверьте, что в настройках Discord включено отображение текущей активности: **Настройки → Игровая активность → Отображать текущую игру как статус**
- Перезапустите программу и Discord

</details>

<details>
<summary><b>Где взять Application ID?</b></summary>

Application ID находится на странице вашего приложения в [Discord Developer Portal](https://discord.com/developers/applications) в разделе **General Information**.

</details>

<details>
<summary><b>Безопасно ли это?</b></summary>

Да. Программа использует официальный протокол Discord Rich Presence и работает локально, не запрашивая ваш логин и пароль.

</details>
